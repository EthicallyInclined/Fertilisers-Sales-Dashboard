# 🌾 Fertilisers Sales Dashboard
## Overview
The Fertilisers Sales Dashboard is a business intelligence and data analytics project developed to analyze fertiliser sales performance using interactive visualizations and KPIs.
This dashboard provides insights into sales trends, product demand, regional performance, and overall revenue generation. The objective is to transform raw sales data into meaningful business decisions through visual storytelling.

## Problem Statement
IFFCO handles fertiliser distribution across multiple regions and product categories. Managing sales performance through traditional reporting methods can make it difficult to identify trends and make timely decisions.

This project aims to solve the following challenges:
- Monitor overall sales performance efficiently
- Identify top-performing fertiliser products
- Analyze region-wise sales contribution
- Track revenue growth over time
- Improve business decision-making using data
